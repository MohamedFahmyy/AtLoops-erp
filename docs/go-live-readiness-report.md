     $$\text{الوعاء الضريبي (Taxable Base)} = \text{الإجمالي الفرعي} - \text{قيمة الخصم التجاري}$$
     $$\text{مبلغ الضريبة} = \text{الوعاء الضريبي} \times \frac{\text{نسبة الضريبة}}{100}$$
     $$\text{الإجمالي النهائي للمطالبة} = \text{الوعاء الضريبي} + \text{مبلغ الضريبة}$$
2. **الحالة المحددة:**
